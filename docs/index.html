01 / CONTROL LOOP

每一个转换，都有一条可以审计的路径。

01

Inspect

读取容器、流、编码、字幕、HDR 与元数据，先建立事实。

media inspect
02

Plan

选择 copy 或 transcode，显示质量损失、警告和最终命令。

media plan
03

Execute

安全地处理路径冲突，进度走 stderr，stdout 保持可解析。

media convert
04

Verify

重新探测并解码输出，检查尺寸、流存在性、时长和目标大小。

media verify

02 / CAPABILITY MATRIX

覆盖常见媒体工作，不隐藏主机边界。

能力列表由命令和本机 FFmpeg 编码器共同决定。缺失编码器时，Agent 收到结构化错误，而不是一个看似成功的假结果。

03 / TOOL API

给 Agent 一个小而明确的接口。

通过 stdin 发送一个 JSON 对象，stdout 返回一个 JSON 对象。支持语义操作、别名、dry-run、显式 overwrite 和 Raw FFmpeg escape hatch。

1 → 1 JSON contract0 implicit overwritestderr progress channel
打开完整 schema ↗ 
printf '%s\n' '{
  "operation": "convert",
  "input": "input.mkv",
  "output_format": "mp4",
  "dry_run": true
}' | media tool
printf '%s\n' '{
  "operation": "image_convert",
  "input": "poster.png",
  "output_format": "webp",
  "width": 1280,
  "image_quality": 85
}' | media tool
printf '%s\n' '{
  "operation": "merge",
  "inputs": ["a.mp4", "b.mp4"],
  "mode": "concat"
}' | media tool
stdout: one JSON response · stderr: diagnostics

04 / OPERATION INDEX

从一个 agent intent 到可复现命令。

READinspect

先知道文件是什么

容器、视频、音频、字幕、HDR、语言、时长与码率。

media inspect input.mkv --json
VIDEOconvert

选择容器与质量

兼容时 remux，必要时转码，报告 codec 与质量损失。

media convert input.mkv --to mp4
IMAGEimage

图片也走同一条契约

格式、尺寸、旋转、水印与质量参数都可 dry-run。

media image poster.png --to webp
ANIMATEgif

从视频生成动图

限定时长、帧率和宽度，使用 palettegen/paletteuse 控制色带。

media gif input.mp4 --duration 3
EDITedit

把滤镜变成语义参数

裁剪、旋转、变速、音量、命名滤镜和字幕烧录。

media edit input.mp4 --speed 1.25
JOINmerge

连接、混流或混音

concat、video-plus-audio mux，以及双音轨 mix。

media merge a.mp4 b.mp4 --mode concat
RECOVERrepair

对坏文件给出下一步

时间戳修复、损坏容忍 remux，或显式选择 re-encode。

media repair damaged.mp4
AUDIOaudio

音频转换不是黑盒

码率、采样率、声道、音量和时间范围全部可见。

media audio input.mp4 --format flac
DISKdisc

能力边界被明确写出

DVD/CD/ISO 走 bridge，ISO authoring 委托本机工具，权限与 DRM 以 warning 呈现。

media disc DVD --action create-iso

没有匹配的 operation。试试 image、merge 或 repair。
